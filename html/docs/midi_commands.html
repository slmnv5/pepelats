MIDI commands


Multi-tapping

There are only few buttons on foot controllers and number of looper commands is much bigger. To deal with it multi-tapping is used. If delay between taps is less than 0.5 seconds they belong to one series and produce MIDI note as explained below.

Assume button A sends note ON message for note 60 with velocity 100. Multiple tapping will send one additional note ON for note 60 with changed velocity.
One additional note ON message will have velocity = number of taps + 5 for a hold in the end.

For this example:

  • one tap sends note 60 velocity = 100 + note 60 velocity = 1
  • double tap sends note 60 velocity = 100 + note 60 velocity = 2
  • triple tap sends note 60 velocity = 100 + note 60 velocity = 3
  • one tap and hold sends note 60 velocity = 100 + note 60 velocity = 1 + 5 = 6
  • double tap and hold sends note 60 velocity = 100 + note 60 velocity = 2 + 5 = 7

Using multi-taps one button sends different MIDI messages with velocities 1,2,3... Multiple taps use 0.5 seconds delay to see if there is next tap. Because of this it should not be used for time critical commands - start playing or recording. Use it for other commands like changing volume, scrolling song list, etc. In menu files we can use one button "a" for different actions:

a : play a1 : start drum a2 : start overdub a3 : stop

Here a - is original note sent instantly without any delay.
a1, a2, a3 - are counted notes delayed by 0.5 seconds + time it takes to tap it 1,2 or 3 times.

Control change messages

If foot controller sends control change (CC) messages from expression pedal the looper can convert them into notes. As example CC 12 will be converted to note 12 ON/OFF.

As an example in iRig Blue Board MIDI foot controller there are two expression pedal inputs. Plugging ON/OFF buttons into these inputs will send CC messages converted into note messages.
