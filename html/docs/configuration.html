Configuration

All configurations except of user license are saved in two files:

  • [user.ini] - user configuration
  • [main.ini] - default configuration

If file user.ini does not have specific configuration it is taken from file main.ini. You may dit file user.ini in the main web page of the [looper].
Thus, for example, you may change names of MIDI or audio devices, MIDI notes used and so on. To see an example of specific configuration look at [main.ini] that contains all default configurations and comments explaining each option.

MIDI configuration

MIDI configuration in [user.ini] / [main.ini] has only three option:

  • input MIDI port names separated by comma, part of name may be used instead of full name and names are case-sensitive, first matching port is used for MIDI input
  • MIDI notes (or CC numbers) that MIDI device sends. This is list of integer values from 0 to 127. Defaults are: 60, 62, 64, 65, 12, 13
    All eneterd values are matched to buttons: a, b, c, d, ... These buttons names appear in menu configurations to specify actions. For example: a1 - clear song, a2-load song, a3-save song, etc. Here a1, a2, a3 are single, double, triple tap on button a. Knowing these rules you may tweak buttons to your preffered way of looping.
  • Computer keyboard keys to use for MIDI messages. Defaults are: 1, 2, 3, 4, q, w Computer keyboard is used only if no MIDI controller is found and it is connected.

Finally if no MIDI controller and computer keyboard are connected the looper starts anyway. It can not be controlled but if you use web to monitor looper you may open log file and check for any errors. You may also edit configuration files to change MIDI controller names so that after restart they get connected.
