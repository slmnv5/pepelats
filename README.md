# Pepelats - Audio looper and drum machine on Raspberry Pi

-	Compatible Raspberry Pi: 3A+, 3B+, Zero-2W, 4, 5
-	Multiple song parts (intro/verse/chorus/...).
-   Any number of parallel loops in a part.
-	Quantization, loop's length, start and stop time are adjusted. 
-	Full history of undo/redo for each song part. 
-	Parts and loops are deleted on the run, loops are silenced, re-arranged.
-	Songs saved, loaded along with drums and settings. 
-	Installation with single command.
-	MIDI controller or computer keyboard as MIDI controller.
-	Three drum machine types with volume control, random variations and breaks. 



To download and run the installer script automatically, copy and paste one of the following commands into your terminal:

### Using wget (Recommended)
```bash
wget -qO- https://github.com | bash
```

### Using curl
```bash
curl -fsSL https://github.com | bash
```

---
*Note: This script will download `pepelats.zip`, install to `~/pepe/` directory, append startup command to `~/.profile`
