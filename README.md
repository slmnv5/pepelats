# Pepelats - Audio looper and drum machine on Raspberry Pi
 
### Hardware required
Raspberry Pi versions: Zero-2W, 3B+, 4, 5


### Latest updates

Single installation command. After Raspberry Pi OS lite is installed single command downloads and installs the looper.

No drum mode – song parts do not quantize as there is no drum. Good if parts need to have different tempo.

Minor improvements and bug fixes.
