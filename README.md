# Pepelats - Audio looper and drum machine on Raspberry Pi
 
### Hardware required
Raspberry Pi versions: Zero-2W, 3A+, 3B+, 4, 5


### Latest updates

Single command downloads and installs the looper.

No drum mode - song parts may have different BPM.

Minor improvements and bug fixes.
